# Proposed v1.0.0 release

**Curated candidate for review; no stable tag yet.** Current package version: 1.0.0rc1.

This first curated software release organizes AI-CVD's research narrative and selected
method implementations, with a fictional-data demonstration and public-only checks.
It distinguishes published AIME feasibility work, internally completed Study A and
Study B's manuscript-in-preparation status.

Included: complete source-neutral telemetry pipeline, retained processing algorithms,
historical source runners, thesis/architecture documentation, installable package,
selected model/feature interfaces, subject-isolated
synthetic demo, tests, citation, research navigation and CI.
Excluded: clinical data, fitted models, historical experiment outputs and private provenance.
No clinical results were changed or regenerated.

## Approval and publication checklist

1. Candidate clearance and owner authorization to publish in the existing AI-CVD
   repository have been confirmed. No local experimental ancestry may be imported.
2. Review the curated candidate through a release branch and pull request. Main-branch
   merge, historical remediation and release tagging remain separate actions.
3. Verify the exact published candidate tree, file manifest and passing public CI.
4. Before a stable release, change package/CFF versions to 1.0.0, refresh manifest
   digests and rerun tests, lint, link, citation and disclosure checks.
5. Obtain final approval for the exact stable-release commit and tag. A clean current
   tree does not remove earlier public Git objects or downloads.

Commands below are for the approved stable-release commit after the preceding
checks and tag approval. They have not been executed:
