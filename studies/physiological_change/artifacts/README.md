# Generated artifacts

Only this README is tracked here. Generated outputs belong in new, ignored run
directories, normally `runs/physiological-change/<run-id>/` from the repository
root. Preserve earlier runs; do not overwrite them.

A future scientific release should contain reproducible original code, permitted
aggregate tables/figures, a model/data card, environment/configuration versions,
source and split hashes, commands and an evidence-linked explanation of results.
Review proposed release artifacts individually. Do not commit raw recordings,
subject-level predictions, identifier mappings or unreviewed generated metadata.
