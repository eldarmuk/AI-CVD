# Changelog

## 1.0.0rc1 — curated candidate, 9 October 2026

- Curated the public tree into an installable ai_cvd package.
- Retained reviewed model definitions for AIME, Study A and Study B, with separately
  labeled earlier-task legacy architectures.
- Added fictional episode generation, subject-isolated splits, tabular fitting,
  untrained temporal inference, metrics and priority-threshold examples.
- Added public-safe regression tests, lint/format checks, file-inventory checks and CI.
- Replaced mixed experimental notes with research navigation and study-specific pages.
- Excluded all clinical data, model artifacts, intermediate outputs, notebooks and exports.
- Public adapters normalize timestamps before episode sorting and validate metric inputs.
  Historical private implementations and scientific results were not changed.

No stable software release has been tagged. This version does not retrospectively
assign software tags to the paper or frozen internal studies.
